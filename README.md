# 岩芯样本切片实验室

运行：

```bash
npm start
```

访问 `http://localhost:3025`。支持样本创建、切片任务、步骤记录和交付统计。

## 耗材批次台账

访问 `http://localhost:3025/consumables`（首页右上角有入口），覆盖染料、研磨盘等耗材：

- **批次登记**：批号、耗材、类别（自动对应切片步骤：切割片→切割、研磨盘→研磨、染料→染色、封片材料→观察）、数量、有效期；批号重复或已过期不能入库。
- **领用登记**：批号、用途、数量、领用人，关联到切片步骤。过期、剩余不足或批号重复（同切片同步骤）的领用**不进领用记录**，只在拒收记录中说明原因；异常批次禁止领用。
- **异常追溯**：按批号查看批次去向和受影响切片；标记异常后波及切片自动停交付，换人复核（不能是标记人或领用人）通过后才恢复。
- **同步显示**：库存、批次去向、停交付清单同源于 `data/consumables.json`，每次操作后整体刷新；停交付中的样本在主页面无法标记交付。
- **步骤记录保留**：领用成功后会在切片步骤日志追加一条领用记录，原有步骤记录不动。

### 三个业务文件

| 文件 | 职责 |
| --- | --- |
| `consumable-store.js` | **保存**：`data/consumables.json` 的读写与初始台账 |
| `consumable-rules.js` | **判定**：效期、剩量、重复批号校验，异常波及与换人复核规则 |
| `consumable-page.js` | **页面**：台账单页界面（库存、批次去向、停交付清单、领用与拒收） |

数据文件：样本切片在 `data/core-slices.json`，耗材台账在 `data/consumables.json`（首次启动自动生成示例数据）。
