# 岩芯样本切片实验室

运行：

```bash
npm start
```

访问`http://localhost:3025`。支持样本创建、切片任务、步骤记录、交付统计与耗材批次台账。

## 耗材批次台账

- **批次入库**：登记批号、耗材名称、对应切片步骤、用途、数量和有效期；批号重复不入库并说明原因。
- **领用登记**：登记批号、用途、数量、有效期和领用人，耗材按批号自动对应到切片步骤；过期、剩量不足或同一切片批号重复时，领用不进记录并说明原因。
- **异常批次**：按批号判定异常后自动列出受影响切片，相关样本先停交付；须换人复核，通过才恢复交付，不通过维持停交付。
- **一屏同步**：耗材库存、批次去向、停交付清单与样本卡片同页刷新；领用、异常、复核结果全部写入切片步骤记录留痕。

## 业务文件

- `src/store.js` — 保存：数据加载/落库与全部写操作
- `src/rules.js` — 判定：入库、领用、交付、复核的校验规则与受影响切片推导
- `src/page.js` — 页面：台账与样本展示
- `server.js` — 路由层，串联判定与保存
